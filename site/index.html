YAML schema

One project per file. Unknown fields and bad dates fail with the file, line and a fix hint. Full JSON Schema lives in schema.json. 

name: Acme website refresh
client: Acme Bakery
status: active            # active | on-hold | done
next_milestone: Homepage review call   # optional
deadline: 2026-03-20      # YYYY-MM-DD
blockers:                 # optional list of strings
  - Waiting for product photos from the client
hours_estimated: 40
hours_spent: 31.5
Project file fields
Field Required Notes
name yes Unique across files (case-insensitive).
client yes Display label only.
status yes active, on-hold, or done.
deadline yes Date only, YYYY-MM-DD. Due today is not overdue.
hours_estimated yes Non-negative number.
hours_spent yes Non-negative number. Over-estimate when spent > estimated.
next_milestone no Short string.
blockers no List of non-empty strings. Ignored when status is done.

Commands

Install from a clone, then point at a directory of project files.

pip install -e .
client-pulse list examples/projects --today 2026-03-16
client-pulse overdue examples/projects --today 2026-03-16
client-pulse blockers examples/projects --today 2026-03-16
client-pulse weekly-report examples/projects --today 2026-03-16
client-pulse weekly-report examples/projects --webhook-url "$URL" --dry-run
client-pulse weekly-report examples/projects \
  --telegram-token "$TELEGRAM_BOT_TOKEN" \
  --telegram-chat-id "$TELEGRAM_CHAT_ID"
